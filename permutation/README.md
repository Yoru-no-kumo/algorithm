# Permutation

## 順列とは

順列とは、与えられた要素を順番を考慮して並べ替える方法のことです。<br>
同じ要素を使っていても、並び順が異なれば別の結果として扱われます。<br>
例えば、`1 2 3`、`2 1 3`、`3 1 2` はすべて異なる順列になります。

## アプローチ

順列を生成するためには、

- まだ使用していない要素を1つ選び
- 現在の位置に配置し
- 再帰的に次の位置を決めていく
という処理を繰り返します。

そのため、
- 訪問管理用の配列（`is_visited`）を使って
- 一度選んだ要素を再び使わないようにし
- バックトラッキングで全ての並びを探索する
という方法を用いました。

## 結果

この方法により、要素の並び順が異なるすべてのパターンを生成できました。
また、順列は組み合わせと異なり、順序の違いをすべて別のケースとして扱うため、
探索の幅が広く、要素数が増えると急激に結果数が増えることも確認できました。<br>

**順列生成では、バックトラッキングの考え方を使って訪問配列（`is_visited`）を管理する方法が最も効果的で、効率も良いです。**

`not in` を使って使用済み要素を判定すると、リスト探索が `O(n)` となり、
再帰呼び出しが多い順列では全体の処理時間が大きく増加します。
そのため、理論的にも実装的にも、訪問配列を使う方法が最適です。

<br><br>

- 入力は全てスペース区切りで行います。また、入力は改行を含めて2回に分けて行います。
- 最初の入力では2つの数字（nとm）を受け取ります。（nは与えられる数列の長さ、mは生成する順列の長さを意味します。）<br>
例えば、`4 3`と入力し次の行で`1 2 3 4`と与えると、4個の要素から3の順列が全て出力されます。
