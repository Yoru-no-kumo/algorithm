# Fibonacci

## フィボナッチ数列とは

フィボナッチ数列（Fibonacci sequence）は、通常1から始まり、直前の2つの数を足して次の数を作っていく数の並びです。数列が1，1，2，3，5，8，13…と続いていきます。

## アプローチ

フィボナッチ数列の n番目の値を求めるには、前の2つの値を足すという同じ処理を繰り返す必要があることが分かります。<br>
そのため、繰り返し処理や再帰処理を使って求められることに気付き、まずは再帰で実装してみました。

## 結果

しかし、再帰にはスタックオーバーフローという問題があるため、次にメモ化を用いることでそれを防ぎ、さらに大きな性能向上も得られました。<br>
また、40番目あたりから処理時間に明確な差は出ることを気づけました。さらに、50番目の以上の値は、単純な再帰処理では結果を得ることができませんでした。

・ 本コードは学習目的のため、n≥2を前提として実装している。<br>
・入力例）7<br>
・出力例）13<br>　　　　　13
