# Fibonacci

## フィボナッチ数列とは

フィボナッチ数列（Fibonacci sequence）は、通常1から始まり、直前の2つの値を足して次の値を求める数列です。  
数列は `1, 1, 2, 3, 5, 8, 13...` のように続いていきます。

## アプローチ

フィボナッチ数列の`n`番目の値を求めるには、前の2つの値を足す処理を繰り返す必要があります。 <br>
そのため、最初は再帰処理を使ってシンプルに実装してみました。<br>
しかし、再帰は同じ計算を何度も繰り返すため、効率が悪く、スタックオーバーフローの危険性もあります。<br>
そこで、計算済みの値を保存して再利用する`メモ化（memoization）`を導入し、大きな性能改善が得られました。

## 結果

実験の結果、40番目あたりから再帰とメモ化の処理時間に明確な差が現れることが確認できました。<br>
また、50番目以上では単純な再帰では結果の取得が困難になり、メモ化が非常に有効であることが分かりました。

- 本コードは学習目的のため、`n≥2`を前提として実装しています。<br>
