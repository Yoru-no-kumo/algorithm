# 時間複雑度（Time Complexity）

## 1. 時間複雑度とは

時間複雑度とは入力サイズ（`n`）が大きくなると、アルゴリズムにどれだけ時間がかかるかを数学的に表した概念です。
正確な実行時間（例: 0.02秒）を指し示すことではなく入力が大きくなるほど、実行時間がどのようなパターンで増加するかを示します。
つまり、時間複雑度は性能の増加率を示す概念

## 2. なぜ実際時間ではなく、増加率を見るのか

### 例えば、同じアルゴリズムでも

- コンピュータの仕様
- プログラミング言語
- コンパイラー
- 最適化オプション
これらによって実際の実行時間が変わります。ですので、「正確な時間」は意味がなく、入力が大きくなると時間がどのように増加するかが最も重要になります。

例えば、

- あるアルゴリズムは入力が10倍増えると実行時間が1倍になる
- あるアルゴリズムは入力が10倍増えると実行時間が100倍になる
この違いが実戦では非常に重要です。

## 3. Big-O表記法とは

時間複雑度を表す時に最も使われる方法はBig-O表記法です。
Big-Oは最悪の場合の基準で、増加率の上限を示す表記法です。
代表的なBig-Oは次の通りです。

|　　表記　　|意味|　例　|
|-----|-----|-----|
|$O(1)$|定数時間|配列インデクスのアクセス|
|$O(\log n)$|ログ時間|二分探索|
|$O(n)$|線形時間|線形探索|
|$O(n\log n)$|ログ線形時間|マージソート、クイックソート 平均|
|$O(n^{2})$|平方時間|バブル/選択/挿入ソート|
|$O(2^{n})$|指数時間|部分集合の生成、バックトラッキングの一部|
|$O(n!)$|階乗時間|順列生成|

## 4. 時間複雑度を理解する最良の方法

ループ構造を分析すれば、すぐに分かります。

例）単一ループ

``` python
for i in range(n):
    print(i)
```

繰り返し回数: n -> Big-O: $O(n)$

例）二重ループ

``` python
for i in range(n):
    for j in range(m):
        print(i + j)
```

繰り返し回数: n x m -> Big-O: $O(n^2)$

$O(n^2)$の理由はnとmの別々のサイズに関わらずに最悪の時間は結局、二乗になるためです。

例）半分ずつ減るループ

``` python
while n > 1:
    n = n // 2
```

繰り返し回数: $\frac{1}{2}$ずつ減る -> Big-O: $O(\log n)$

半分ずつ減るループの繰り返し回数をkとしたら、
$$
\frac{n}{2^k} = 1
$$
この式を`k`について解くと
$$
k = \log_2 n
$$
になります。それとも、時間複雑度では定数や底（base）を無視するため
、結局
$$
O(\log n)
$$
になります。

## 5. 選択ソート（Selection Sort）

配列の中から最小（または最大）の要素を探し、それを先頭（最大の場合は後尾）に持ってくる操作を繰り返すシンプルなソートアルゴリズムです。

### アルゴリズムの流れ（昇順の場合）

1. 配列の未整列部分から最小値を探す
2. その最小値を未整列部分の先頭と交換する
3. 未整列部分を1つ減らして繰り返す

### 選択ソートの時間複雑度は

1. 全体の配列で最小値を探す -> n回比較
2. 次の位置でまた最小値を探す -> n-1回比較
3. またその次の位置で最小値を探す -> n-2回比較
4. 繰り返し
5. 最後には1回比較

つまり、比較の回数は
$$
n+(n-1)+(n-2)+\dots +1=\frac{n(n-1)}{2}
$$
これをBig-Oで表したら,
$$
O(n^{2})
$$
になります。

## 6. 纏め

1. 時間複雑度は入力が大きくなると、実行時間がどのように増加するのかを表す。
2. Big-Oは増加率の上限を示す表示法
3. ほとんどの時間複雑度はループの構造を見ればすぐにわかる。
